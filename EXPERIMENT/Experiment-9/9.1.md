## Aim

To create a row-level `BEFORE UPDATE` trigger that limits an employee's salary increase to 15% of the old salary.

## Question

Create a `Salary_Hike` table and a row-level trigger that rejects a salary update when the new salary is more than 15% higher than the old salary. Demonstrate a permitted update and a rejected update.

## Theory

A row-level trigger runs once for every row affected by a statement. In Oracle, `:OLD` and `:NEW` refer to the row values before and after the update. Comparing `:NEW.salary` with `:OLD.salary * 1.15` lets the trigger enforce a maximum increase of 15%. An application error is raised when the limit is exceeded, preventing that update.

## SQL Query Used

The runnable script is [9.1.sql](9.1.sql).

```sql
CREATE TABLE Salary_Hike (
    employee_id NUMBER PRIMARY KEY,
    employee_name VARCHAR2(100),
    salary NUMBER(10, 2)
);

INSERT INTO Salary_Hike VALUES (101, 'Amit', 50000);
INSERT INTO Salary_Hike VALUES (102, 'Rahul', 60000);

CREATE OR REPLACE TRIGGER Salary_Hike_Trigger
BEFORE UPDATE OF salary ON Salary_Hike
FOR EACH ROW
DECLARE
    salary_limit_exceeded EXCEPTION;
BEGIN
    IF :NEW.salary > :OLD.salary * 1.15 THEN
        RAISE salary_limit_exceeded;
    END IF;
EXCEPTION
    WHEN salary_limit_exceeded THEN
        RAISE_APPLICATION_ERROR(
            -20001,
            'Salary increase cannot exceed 15% of the old salary.'
        );
END;
/

UPDATE Salary_Hike
SET salary = 57000
WHERE employee_id = 101;

BEGIN
    UPDATE Salary_Hike
    SET salary = 70000
    WHERE employee_id = 102;
EXCEPTION
    WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE(SQLERRM);
END;
/

SELECT * FROM Salary_Hike;
```

## Result

The trigger allowed Amit's 14% salary increase and rejected Rahul's increase of more than 15%. The final table retained Rahul's original salary.
