## Aim

To understand the use of the `ORDER BY` clause with the `COUNT()` function and `GROUP BY` clause in SQL for sorting grouped records.

---

## Question

Write an SQL query to count the number of employees in each city and sort the result in **descending order of employee count**. If two cities have the same employee count, sort them in **ascending alphabetical order** based on the city name.

---

## Theory

The `GROUP BY` clause is used to group rows having the same values in a specified column, while the `COUNT()` function counts the number of records in each group. The `ORDER BY` clause is then used to sort the grouped results.

In this query:

- `GROUP BY emp_city` groups employees according to their city.
- `COUNT(emp_id)` counts the total number of employees in each city.
- `ORDER BY CNT DESC` sorts the cities by employee count in descending order.
- `EMP_CITY ASC` acts as a secondary sorting condition when two or more cities have the same count.

This approach is useful for generating sorted summary reports based on grouped data.

---

# SQL Query Used

```sql
SELECT emp_city,
COUNT(emp_id) AS CNT
FROM employees
GROUP BY emp_city
ORDER BY CNT DESC, emp_city ASC;
```
