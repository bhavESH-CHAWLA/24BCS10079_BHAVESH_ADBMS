## Aim

To understand the working of the `UNION` operator in SQL by combining rows from two tables (`Arts` and `Science`) into a single result set.

---

## Question

Write an SQL query to combine all records from the **Arts** and **Science** tables using the `UNION` operator.

---

## Theory

The `UNION` operator is used to combine the results of two or more `SELECT` statements into a single result set.

Rules for using `UNION`:
- Both `SELECT` statements must return the **same number of columns**.
- Corresponding columns must have **compatible data types**.
- The columns should appear in the **same order**.
- `UNION` removes duplicate rows automatically.

---

# SQL Query Used

```sql
SELECT *
FROM Arts

UNION

SELECT *
FROM Science;
```
