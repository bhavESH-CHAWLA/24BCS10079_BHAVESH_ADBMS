## Aim

To understand the working of the `INTERSECT` operator in SQL by retrieving the common records present in both the **fruit** and **inventory** tables.

---

## Question

Write an SQL query to display the names of fruits that are available in the supermarket by finding the common values between the **fruit** and **inventory** tables using the `INTERSECT` operator.

---

## Theory

The `INTERSECT` operator returns only those rows that are common to the results of two `SELECT` statements.

Rules for using `INTERSECT`:
- Both `SELECT` statements must return the **same number of columns**.
- Corresponding columns must have **compatible data types**.
- The columns must appear in the **same order**.
- Only duplicate values present in both result sets are returned once.

---

# SQL Query Used

```sql
SELECT f_name
FROM fruit

INTERSECT

SELECT inv_name
FROM inventory;
```
