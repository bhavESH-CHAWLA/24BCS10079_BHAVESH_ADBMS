## Aim

To update the salary of employees belonging to department `10` using a PL/SQL block and display the number of rows updated.

## Question

Write a PL/SQL block to increase the salary of all employees in department `10` by 10%. Use `SQL%ROWCOUNT` to display the number of employees whose salary was updated. If no employee is found, display an appropriate message.

## Theory

PL/SQL supports procedural programming features such as variables, conditional statements, and transactions. The `UPDATE` statement modifies the salaries of employees in the specified department. The implicit cursor attribute `SQL%ROWCOUNT` returns the number of rows affected by the most recently executed DML statement.

## SQL Query Used

```sql
BEGIN
    UPDATE employees
    SET salary = salary * 1.1
    WHERE department_id = 10;

    IF SQL%ROWCOUNT > 0 THEN
        DBMS_OUTPUT.PUT_LINE(
            SQL%ROWCOUNT || ' rows updated.'
        );
    ELSE
        DBMS_OUTPUT.PUT_LINE('No rows updated.');
    END IF;
END;
/
```

## Output

```text
3 rows updated.

PL/SQL procedure successfully completed.
```
